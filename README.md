# ctfmap

## Что это?

Платформа для агрегации российских CTF соревнований.
Цель платформы - собрать участников соревнований и их организаторов на единой платформе.  

## Продукты?

1. Соревнование
2. Участники
3. Организаторы

## Зачем?

1. Участник - новичкам нужна команда и подходящее соревнование + материал, чтобы учится.
2. Организаторы - нужны участники и факт существования соревнования. Также возможна помощь от крупных и сильных команд
3. Развитие цтф по всей стране
