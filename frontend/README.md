# Фронтенд CTF-КАРТЫ

Фронтенд интерактивной карты актуальных CTF-соревнований России.

## Запуск

```bash
npm install
npm run dev
```

Сборка для публикации:

```bash
npm run build
npm run preview
```

## Стек

- React + TypeScript + Vite;
- нативный SVG для карты и маркеров;
- обычный CSS без готового набора компонентов и картографических библиотек;
- публичные данные бэкенда с локальным демонстрационным набором для автономного режима.

## Реализовано

- SVG-карта субъектов России;
- деление на Центральную Россию, Сибирь и Дальний Восток;
- контурная подсветка регионов при наведении и нажатии;
- фильтры: профессиональные, локальные и тренировочные CTF;
- SVG-флаги и импульсы событий без движущихся линий связи;
- изменение яркости флагов и обратный отсчёт по мере приближения старта;
- карточки соревнований при наведении и нажатии;
- статистика выбранного региона;
- отдельная страница события `/events/:slug`;
- рейтинг CTFтайм и уровень сложности;
- единое досье соревнования с расписанием, условиями, «Новости CTF» и учебными материалами;
- открытый просмотр карты и карточек без регистрации;
- страница «О нас» и подача заявки организатором после регистрации;
- горизонт событий — 30 дней.

## Данные границ

GeoJSON содержит 89 субъектов из российского перечня на 12.08.2026. Базовые геометрии получены из [geoBoundaries](https://www.geoboundaries.org/) на основе OpenStreetMap/Wambacher, лицензия ODbL 1.0; недостающие субъекты добавлены в локальный набор. Файл хранится в `public/data/russia-regions.geojson`.
