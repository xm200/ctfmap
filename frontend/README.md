# CTFMAP Frontend

Frontend MVP интерактивной карты актуальных CTF-соревнований России.

## Запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

## Стек

- React + TypeScript + Vite;
- нативный SVG для карты и маркеров;
- обычный CSS без UI-kit и картографических библиотек;
- локальные демонстрационные данные без backend.

## Реализовано

- SVG-карта субъектов России;
- деление на Центральную Россию, Сибирь и Дальний Восток;
- контурная hover/click-подсветка регионов;
- фильтры: элитные, локальные и тренировочные CTF;
- SVG-флаги, импульсы, движущиеся сигналы и линии связи;
- hover/click-карточки соревнований;
- статистика выбранного региона;
- отдельная страница события `/events/:slug`;
- рейтинг CTFtime и уровень сложности;
- горизонт событий — 30 дней.

## Данные границ

Упрощённый GeoJSON ADM1 получен из [geoBoundaries](https://www.geoboundaries.org/) на основе OpenStreetMap/Wambacher, лицензия ODbL 1.0. В локальную конфигурацию карты также добавлены отдельные геометрии Крыма, Донецка и Луганска из совместимого ADM1-набора. Файл хранится в `public/data/russia-regions.geojson`.
