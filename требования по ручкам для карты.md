API соревнований для карты — MVP
Задача
Бэкенд должен предоставить:
Список актуальных соревнований для отображения флагов на карте.
Полную информацию об одном соревновании для отдельной страницы.
Фронтенд не должен самостоятельно вычислять координаты или статус соревнования.
1. События для карты
GET /api/v1/events/map
Query-параметры

Параметр	Обязательный	Описание
from	Нет	Начало периода в ISO 8601. По умолчанию — текущее время
to	Нет	Конец периода в ISO 8601. По умолчанию — текущее время + 30 дней
categories	Нет	Категории через запятую: elite,local,training
Пример:
GET /api/v1/events/map?from=2026-08-12T00:00:00Z&to=2026-09-11T23:59:59Z&categories=elite,local,training

Enum-значения
category:
- elite
- local
- training

format:
- online
- offline
- hybrid

status:
- upcoming
- active
- finished
- cancelled

difficulty:
- beginner
- medium
- hard
- expert
status вычисляет бэкенд:
cancelled — соревнование отменено.
upcoming — текущее время меньше startAt.
active — текущее время между startAt и endAt.
finished — текущее время больше endAt.
Требования к данным
Названия полей в API — camelCase.
Даты возвращаются в ISO 8601, предпочтительно в UTC.
lat и lng возвращаются готовыми: фронтенд не выполняет геокодирование.
Необязательные ссылки возвращаются как null, а не пустой строкой.
slug должен быть уникальным.
regionId должен совпадать с идентификаторами регионов на фронтенде.
Выборка из БД
Основные сущности:
events
organizers
regions
Условие попадания события в выбранный период:
WHERE events.published = true
  AND events.start_at <= :to
  AND events.end_at >= :from
ORDER BY events.start_at ASC;
Это условие учитывает как будущие, так и уже начавшиеся, но ещё не завершившиеся соревнования.
